# АО «Чугунный век» — Telegram Mini App

Чёрная комедия-симулятор выживания на заводе в Едрёносталь. Чистый HTML/CSS/JS, без сборки и зависимостей.

## Запуск локально
```
python3 -m http.server 8000     # открыть http://localhost:8000
```

## Публикация и подключение к Telegram
1. Загрузите папку в репозиторий GitHub (корень репозитория = эта папка).
2. Settings → Pages → Deploy from branch → `main` / root. Получите URL вида `https://<логин>.github.io/<репо>/` (нужен HTTPS).
3. В @BotFather: `/newbot`, затем `/newapp` (выбрать бота, указать URL) **или** `/setmenubutton` с этим URL.
4. Либо запустите `bot/bot.py` (см. docstring) — он добавит кнопку «Выйти на смену».

## Общий рейтинг (вкладка «Рейтинг»)
GitHub Pages — статический хостинг, поэтому общему рейтингу нужен небольшой сервер: `server/server.py` (Python + SQLite).
1. Разверните `server/` на любом хостинге с HTTPS (VPS, Render, Railway, Fly.io и т. п.):
   `pip install -r requirements.txt`, затем `BOT_TOKEN=... ALLOWED_ORIGIN=https://<логин>.github.io python server.py`.
   `BOT_TOKEN` нужен, чтобы проверять подпись Telegram: подделать чужой профиль нельзя.
2. В `js/config.js` впишите `API_URL: 'https://ваш-сервер'` и выложите обновление на GitHub Pages.
3. Рейтинг считает: очки жизни, смены, должность (лучшие значения игрока за все забеги). Игрок может скрыть себя в «Деле».
Защита: проверка подписи Telegram, лимит частоты, проверка правдоподобия (смен ≤ дней, очки ограничены темпом). Игроки, открывавшие отладочное меню, в рейтинг не попадают.
Локальный тест без Telegram: `DEV=1 python server.py`, а в консоли игры `localStorage.setItem('cv_dev_id','любое_имя')`.

## Админ-кабинет и модерация чата (бесплатно, Google Apps Script)
Код — `server/chat_gas.gs` (тот же скрипт, что обслуживает чат). Обновление:
1. Замените код в Apps Script на содержимое файла. В «Настройки проекта → Свойства скрипта» добавьте `BOT_TOKEN` (токен бота) и `OWNER_ID` (ваш числовой Telegram ID, узнать у @userinfobot).
2. «Развернуть → Управление развёртываниями → Новая версия» — URL не меняется.
3. Откройте игру из Telegram: в «Дело → Настройки» появится кнопка «🛡 Админ-кабинет» (только у владельца и назначенных им админов).

Защита: личность проверяется по подписи Telegram (HMAC) на сервере; роль определяется только сервером (владелец — `OWNER_ID`, админы — лист `admins`, менять их может только владелец); опасные действия требуют одноразового подтверждения; все действия и отказы пишутся на лист `audit` (кто, над кем, что, когда, причина).
Тест серверной логики: `node tests/admin_gas_test.js`.

## Радио
Полоса внизу экрана: «Маяк», «Ретро FM», «Радио 7 на семи холмах». Звук включается только по нажатию. Адреса потоков (только https, только официальные/разрешённые) владелец вводит в «Админ-кабинет → Радио»; по умолчанию они пусты.

## Обновления без потери прогресса
Сохранения при загрузке автоматически дополняются новыми полями (`G.migrate`), старые значения не стираются. Для обновления: правите код, повышаете `VERSION` в `js/config.js`, пушите на GitHub. Номер схемы `SAVE_VERSION` меняйте только при несовместимых изменениях.

## Длительность прохождения (темп)
В `js/config.js`: `PACE` (множитель требований к стажу и баллам) и `AUTO_PER_WEEK` (лимит автосмен). Оценка по ботам (не по живым игрокам): до «Начальника цеха» ≈ 760 смен при `PACE: 1`, ≈ 1140 при `1.5`; смена вручную ≈ 70 действий, на автосмене ≈ 8.

## Структура
- `index.html`, `css/style.css`
- `js/data_base.js` — профессии, образование, предметы, меню, викторина
- `js/data_npcs.js` — персонажи, расписания, диалоги
- `js/engine.js` — время, шкалы, зарплата, «поймали/пронесло», сохранение
- `js/career.js` — кадры, инструктажи, среда (проверка ОТ), аттестация, медкомиссия, концовки
- `js/actions.js` — запуск действий, люди, романтика, магазин, банк, телефон, блог
- `js/data_actions.js` — все действия: цех, дом, город, «отчибучить», подработки
- `js/data_events.js` — случайные события, бинокль директора, поломки
- `js/config.js` — версия, адрес рейтинга, темп; `js/leaderboard.js` — клиент рейтинга; `server/` — сервер рейтинга
- `js/radio.js` — радио; `js/srv.js` — связь с сервером (онлайн, бан, параметры); `js/admin.js` — админ-кабинет
- `js/avatars.js`, `js/minigames.js`, `js/ui.js`, `js/main.js`
- `assets/` — фоны (вывеска исправлена на «АО»)

## Сохранение и отладка
Прогресс автоматически пишется в `localStorage` (в Telegram — на устройстве). Отладочное меню: 7 тапов по портрету героя.
Ключи сохранения: `chugunny_vek_save_v1`, рекорды: `chugunny_vek_records_v1`.
