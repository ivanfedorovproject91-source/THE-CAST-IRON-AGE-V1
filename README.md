# АО «Чугунный век» — Telegram Mini App

Чёрная комедия-симулятор выживания на заводе в Едрёносталь. Чистый HTML/CSS/JS, без сборки и зависимостей.

## Запуск локально
```
python3 -m http.server 8000     # открыть http://localhost:8000
```

## Публикация и подключение к Telegram
1. Загрузите папку в репозиторий GitHub (корень репозитория = эта папка).
2. Settings → Pages → Deploy from branch → `main` / root. Получите URL вида `https://<логин>.github.io/<репо>/` (нужен HTTPS).
3. В @BotFather: `/newbot`, затем `/newapp` (выбрать бота, указать URL) **или** `/setmenubutton` с этим URL.
4. Либо запустите `bot/bot.py` (см. docstring) — он добавит кнопку «Выйти на смену».

## Структура
- `index.html`, `css/style.css`
- `js/data_base.js` — профессии, образование, предметы, меню, викторина
- `js/data_npcs.js` — персонажи, расписания, диалоги
- `js/engine.js` — время, шкалы, зарплата, «поймали/пронесло», сохранение
- `js/career.js` — кадры, инструктажи, среда (проверка ОТ), аттестация, медкомиссия, концовки
- `js/actions.js` — запуск действий, люди, романтика, магазин, банк, телефон, блог
- `js/data_actions.js` — все действия: цех, дом, город, «отчибучить», подработки
- `js/data_events.js` — случайные события, бинокль директора, поломки
- `js/avatars.js`, `js/minigames.js`, `js/ui.js`, `js/main.js`
- `assets/` — фоны (вывеска исправлена на «АО»)

## Сохранение и отладка
Прогресс автоматически пишется в `localStorage` (в Telegram — на устройстве). Отладочное меню: 7 тапов по портрету героя.
Ключи сохранения: `chugunny_vek_save_v1`, рекорды: `chugunny_vek_records_v1`.
