# АО «Чугунный век» — Telegram Mini App

Чёрная комедия-симулятор выживания на заводе в Едрёносталь. Чистый HTML/CSS/JS, без сборки и зависимостей.

## Запуск локально
```
python3 -m http.server 8000     # открыть http://localhost:8000
```

## Публикация и подключение к Telegram
1. Загрузите папку в репозиторий GitHub (корень репозитория = эта папка).
2. Settings → Pages → Deploy from branch → `main` / root. Получите URL вида `https://<логин>.github.io/<репо>/` (нужен HTTPS).
3. В @BotFather: `/newbot`, затем `/newapp` (выбрать бота, указать URL) **или** `/setmenubutton` с этим URL.
4. Либо запустите `bot/bot.py` (см. docstring) — он добавит кнопку «Выйти на смену».

## Общий рейтинг (вкладка «Рейтинг»)
GitHub Pages — статический хостинг, поэтому общему рейтингу нужен небольшой сервер: `server/server.py` (Python + SQLite).
1. Разверните `server/` на любом хостинге с HTTPS (VPS, Render, Railway, Fly.io и т. п.):
   `pip install -r requirements.txt`, затем `BOT_TOKEN=... ALLOWED_ORIGIN=https://<логин>.github.io python server.py`.
   `BOT_TOKEN` нужен, чтобы проверять подпись Telegram: подделать чужой профиль нельзя.
2. В `js/config.js` впишите `API_URL: 'https://ваш-сервер'` и выложите обновление на GitHub Pages.
3. Рейтинг считает: очки жизни, смены, должность (лучшие значения игрока за все забеги). Игрок может скрыть себя в «Деле».
Защита: проверка подписи Telegram, лимит частоты, проверка правдоподобия (смен ≤ дней, очки ограничены темпом). Игроки, открывавшие отладочное меню, в рейтинг не попадают.
Локальный тест без Telegram: `DEV=1 python server.py`, а в консоли игры `localStorage.setItem('cv_dev_id','любое_имя')`.

## Админ-кабинет и модерация чата (бесплатно, Google Apps Script)
> **Режим «только владелец».** Сейчас админ-кабинетом может пользоваться только владелец (`OWNER_ID`). Назначенные админы (лист `admins`) записываются, но доступа к кабинету не получают — это сделано намеренно (см. `admin_` в `chat_gas.gs`). Чтобы вернуть модераторов, уберите проверку `r.role !== 'owner'` в начале `admin_` и обновите `tests/admin_gas_test.js`.

Код — `server/chat_gas.gs` (тот же скрипт, что обслуживает чат). Обновление:
1. Замените код в Apps Script на содержимое файла. В «Настройки проекта → Свойства скрипта» добавьте `BOT_TOKEN` (токен бота) и `OWNER_ID` (ваш числовой Telegram ID, узнать у @userinfobot).
2. «Развернуть → Управление развёртываниями → Новая версия» — URL не меняется.
3. Откройте игру из Telegram: в «Дело → Настройки» появится кнопка «🛡 Админ-кабинет» (только у владельца).

Защита: личность проверяется по подписи Telegram (HMAC) на сервере; роль определяется только сервером (владелец — `OWNER_ID`); опасные действия требуют одноразового подтверждения; все действия и отказы пишутся на лист `audit` (кто, над кем, что, когда, причина).
Тест серверной логики: `node tests/admin_gas_test.js`.

## Радио
Полоса внизу экрана: «Маяк», «Ретро FM», «Радио 7 на семи холмах». Звук включается только по нажатию. Адреса потоков (только https, только официальные/разрешённые) владелец вводит в «Админ-кабинет → Радио»; по умолчанию они пусты.

## Обновления без потери прогресса
Сохранения при загрузке автоматически дополняются новыми полями (`G.migrate`), старые значения не стираются. Для обновления: правите код, повышаете `VERSION` в `js/config.js`, пушите на GitHub. Номер схемы `SAVE_VERSION` меняйте только при несовместимых изменениях.

## Длительность прохождения (темп)
В `js/config.js`: `PACE` (множитель требований к стажу и баллам) и `AUTO_PER_WEEK` (лимит автосмен). `PACE` масштабирует сроки карьерной лестницы (`career_ladder.js`). При `PACE: 1` до «Начальника цеха» ≈ 485 смен, до «Зам. генерального директора» ≈ 605, до высшей ступени ≈ 705; при текущем `1.5` (стоит в конфиге) — в полтора раза больше: «Начальник цеха» ≈ 728 смен, «Зам. генерального директора» ≈ 908, высшая ступень ≈ 1058. Смена вручную ≈ 70 действий, на автосмене ≈ 8.

## Правки по QA-проверке V3.17 (`QA_REPORT.md`)
- **Курсы и экзамен:** условия повышения — стаж + экзамен + репутация. Корочка на ступень (`D.REQ[ступень].certs`) необязательна, но даёт −1 к порогу экзамена (минимум 2 верных ответа из 5). Подсказки в меню курсов и в списке требований это объясняют.
- **Концовки** (`js/endings_extra.js`): «Тюрьма» — 3 поимки с добычей за 120 дней (на второй — предупреждение Соплежуйкина); «Бездомный» — долг от 120 000 ₽ + зависимость (`habit` ≥ 60) + менее 2 000 ₽ на руках 8 недель подряд (предупреждение на 4-й). Мёртвая концовка `puppet` удалена.
- **Закрытие завода:** вместо мгновенного конца — 4 недели на спасение (договориться за 20 000 ₽, поручиться перед начальством, либо показатели завода ≥ 65 дают шанс на самоспасение). После спасения 26 недель угрозы нет.
- Тест: `python3 tests/qa_fixes_test.py`.

## V3.7: начальство, конфликты, Тамара, настроение (`js/v38.js`)
- **Репутация у начальства** (`G.bossStanding()`): брак, выговоры, ТБ, опоздания, план, качество, дисциплина, инициатива. Все показатели затухают каждую смену, у каждого фактора есть потолок — одно мелкое нарушение отношения не ломает. Карточка — на вкладке «Смена».
- **Субординация**: мастера (`stepanych`, `dudukin`), руководство цеха (`shchiplen`, `kulezhov`, `rassvetov`), высшее (`soplezhuykin`, `truhanov`) говорят через `G.bossTalk`. Фамильярность наказывается тем строже, чем выше начальник, и допустима только при достаточных должности и отношении (таблица `FAM`). Реплики персонажей — таблицы `L` и `STY`.
- **Придирки**: частота и вид (`evInspect/evError/evRemark/evCheck/evExplain`) зависят от репутации; при хорошей — «доверие» (`evTrust`). Лимиты событий в день — в `bossRoll`.
- **Конфликты**: `confRoll/conflict`, 6 вариантов ответа, память в `s.flags.v38.conf[id]`, напоминание о ссоре в разговоре, паузы против повторов.
- **Тамара Ивановна**: окно на входе в цех отключено, утром на проходной — только карточка с кнопкой; уборка по вторникам и пятницам (`CLEAN_DAYS`), показатель `s.world.clean` влияет на качество и опрятность.
- **Настроение**: стадии ≤30/20/10/5, штрафы по часам, нервный срыв вместо мгновенного конца; повторный ноль за 10 дней — уход с завода.
- Данные модуля лежат в `s.flags.v38`, старые сохранения подхватываются сами. Тест: `python3 tests/v38_test.py`.

## Карьера (V3.8)
- Стажировка — 5 смен, затем экзамен у Соплежуйкина (5 вопросов). Дальше разряды 1–5 и управленческие ступени; сроки — в `WORK_BASE`/`MGMT_BASE` (`js/career_ladder.js`).
- Порог экзамена: 3 из 5 на разряды 1–2, 4 из 5 выше. Репутация у начальства (`G.bossStanding`): «хорошая» — порог −1, «плохая» — +1, «худшая» — допуск к экзамену закрыт на 3 смены. С 3-го разряда и в аттестации руководителей 3 вопроса из 5 берутся из «сложных» (`WORK_HARD`/`MGMT_HARD`).
- Если закрыть игру посреди экзамена, попытка считается использованной, но повышение не блокируется.

## V3.15: доработки по отзывам (`js/v39.js`)
- **Проходная**: мастера участка и выше (ранг 6+) Егорыч пропускает всегда — без придирок и «забытого пропуска».
- **«Отчибучить»**: выходки открываются постепенно (разряд, стаж, крутизна); не более двух в день, у каждой — пауза 3 дня. У руководителей (ранг 6+) свой набор по ступеням должности, а при поимке — «вызов на ковёр» со штрафом по должности, влиянием на план и настроение цеха.
- **Нормативная документация**: чем дольше не подписаны документы, тем ниже репутация у начальства (фактор `docs` в `G.bossStanding`) и каждую смену падает отношение; плашки «Нужно расписаться» и «Репутация у начальства» показываются только на работе.
- **Настроение**: с похмелья потолок настроения 55 (лёгкое) / 35 (тяжёлое) — `G.hangMoodCap()`. Исправлен «голодный обрыв» в `v34.js` (раньше настроение мгновенно ставилось в 6 и удерживалось). В окне «Вы на грани» все способы работают без телефона (`G.moodReliefOpts`, `G.moodTalk`), вместо «Понял(а), исправлюсь» — «Ок».
- **Баба Нюра** (`G.nyuraMenu`): соседка — чай, пирожки, сплетни, подработки (каждый день бывает дело, чем лучше отношения, тем чаще и щедрее). Присутствует только при жилье «Общага» (`G.nyuraHere`); при переезде пропадает из «Людей» и «Своих людей».
- **Чугунок**: погладить/поиграть заметно повышает настроение (растёт с доверием кота, за день — не бесконечно), плюс встреча дома после смены и карточка на вкладке «Дом».
- **«Помыться»** — раз в день.
- **«Свои люди»**: в меню друга — «Пригласить» (домой, в бар, на рыбалку, в гости) — `G.inviteMenu`; иногда друг бывает занят; помощь друзей по утрам показывается уведомлением.
- Тест: `python3 tests/v39_test.py`.

## Облачное сохранение
`js/cloud.js` дублирует сохранение в Telegram CloudStorage (куски по 3500 символов, метка `cv_meta` пишется последней). На новом устройстве без локального сохранения прогресс подтягивается автоматически; если облако новее локального — игра спрашивает. Вне Telegram модуль ничего не делает.

## Тесты
`node tests/admin_gas_test.js` и `python3 tests/*_test.py` (нужен `playwright`). Те же проверки запускает GitHub Actions (`.github/workflows/tests.yml`). `tests/audit_fixes_test.py` покрывает исправления V3.8.

- `js/radio.js` — радио; `js/srv.js` — связь с сервером (онлайн, бан, параметры); `js/admin.js` — админ-кабинет
- `js/v38.js` — начальство, придирки, конфликты, уборка, стадии настроения
- `js/v39.js` — V3.15: похмелье и настроение, Баба Нюра, «Отчибучить» по должностям, приглашения друзей

- `js/avatars.js`, `js/minigames.js`, `js/ui.js`, `js/main.js`
- `assets/` — фоны (вывеска исправлена на «АО»)
