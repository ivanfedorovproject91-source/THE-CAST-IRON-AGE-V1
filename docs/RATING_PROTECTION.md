# Защита рейтинга и секреты (Этап 5)

## Что проверено
- **Секреты в клиенте и репозитории.** В `js/`, `index.html` и во всей истории git (все ветки) нет токенов бота, ключей Google и приватных ключей. Единственное совпадение — тестовая заглушка `BOT_TOKEN: '123:TESTTOKEN'` в тесте. Адреса `API_URL` и `CHAT_URL` (Apps Script `…/exec`) публичны по своей природе — клиент обязан их знать; безопасность держится на проверке на сервере, а не на секретности адреса.
- **Токен бота** хранится только в свойствах скрипта Apps Script (`BOT_TOKEN`) — так и должно быть. Если когда-либо токен попадал в чат, скриншот или публичный файл — перевыпустите его в @BotFather (`/revoke`) и обновите свойство скрипта. В отчёт значение не копируется.
- **Что делает клиент:** читы и вручную вставленные сохранения исключены из отправки результата (`flags.dbg`, `flags.imported`); отправка не чаще раза в 45 с; результат подписан данными Telegram (`initData`), проверяемыми на сервере.
- **Что клиент защитить не может:** любой код в браузере можно подделать. Поэтому единственная настоящая защита рейтинга — сервер (ваш Apps Script). Ниже — что в нём уже есть и что я рекомендую добавить.

## Что уже есть в вашем Apps Script (проверено по присланному файлу)
- проверка подписи Telegram (HMAC) при заданном `BOT_TOKEN`;
- обрезка значений (`int_`), очистка имени, лимит частоты (15 с), блокировка записи, `shifts ≤ days + 3`;
- рекорд игрока только растёт (`Math.max`).

## Что нужно сделать вам (я не меняю чужой сервер)
1. **Свойства скрипта:** `BOT_TOKEN` задан **и** `REQUIRE_TELEGRAM = 1`. Без второго любой желающий пишет в рейтинг от имени `dev:…` без подписи.
2. **Добавить проверки правдоподобия** в `save_` (после `int_`‑ограничений). Пороги подберите по своей таблице (99-й перцентиль честных игроков), цифры ниже — отправная точка:
```js
// не более 1 смены в игровой день и ранг не выше, чем позволяет темп
if (rank > 1 + Math.floor(shifts / 8) + 1) throw new Error('implausible rank');
// рост очков между отправками: не быстрее 1500 за минуту реального времени
const prev = Number(row[COL.oj]) || 0, dt = (Date.now() - (Number(row[COL.ts]) || 0)) / 60000;  // нужна колонка ts
if (idx >= 0 && oj - prev > 1500 + 1500 * dt) throw new Error('implausible growth');
// деньги и зарплата — в разумных пределах для ранга
if (pay > 40000 * (rank + 1) * 1.6 + 400000) throw new Error('implausible pay');
```
3. **Журнал отклонённых отправок** (лист `Rejects`: id, причина, время) — чтобы видеть, не режет ли порог честных игроков.
4. **Ручной бан** уже есть в админке (`srv.js`/`CHAT_URL`) — используйте для подтверждённых читеров.

## Ограничение
Клиентская проверка `dbg`/`imported` — лишь вежливость: игрок может править `localStorage`. Серверные пороги выше ограничат ущерб, но полностью исключить подделку без серверной симуляции игры нельзя.
