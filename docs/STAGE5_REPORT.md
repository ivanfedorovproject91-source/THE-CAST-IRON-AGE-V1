# Этап 5: техническая стабилизация — отчёт

## 5.1 Сохранения (js/stage5_saves.js)
- **Копия перед миграцией:** при первой загрузке после смены версии исходная запись целиком копируется в `…_premig` (+ метаданные от/до версии). Повторно не перезаписывается.
- **Проверка после миграции:** деньги, долг, кредиты/ипотеки (остаток, платёж, число записей истории), квартира и владения, ранг, смены, день, имя должны остаться **байт-в-байт** теми же (`G.saveInvariants`). Иначе — запись в журнал, плашка игроку, копия остаётся.
- **Скользящая копия** (не чаще раза в 10 минут и только для состояния без NaN/выходов за диапазон).
- **Повреждённое сохранение не стирается:** уходит в `…_corrupt`, игра пробует восстановиться из скользящей копии, затем из копии «до обновления»; если ничего не помогло — исходный текст остаётся как был.
- Меню разработчика → «Сохранение»: копия сейчас, возврат копий (текущее откладывается в запасной слот), экспорт/импорт (импортированное сохранение не идёт в рейтинг).

## 5.2 Облако Telegram (js/cloud.js)
Риск: запись «новее» не значит «дальше»; запуск с нового устройства или «Начать снова» молча затирали облачный прогресс.
- Метка облака хранит прохождение (`rs`), смены, день. Решение — чистой функцией `G.cloud.decide` (восстановить / записать / спросить / ничего).
- Разные прохождения: если в облаке больше прогресса — всегда вопрос; запись в облако **блокируется**, пока выбор не сделан.
- «Начать снова» после старта: пока новое прохождение не догнало облачное, перезапись — только с явным согласием.
- Перед загрузкой из облака локальное сохранение откладывается в `…_before_cloud`.

## 5.3 Диагностика (index.html, js/stage5_diag.js)
- Не загрузившиеся файлы (404, обрыв) ловятся в фазе захвата; проверяется наличие ключевых функций каждого модуля; при проблеме — плашка сверху + «Подробнее» с копируемым отчётом; журнал в `cv_diag`. Внешний скрипт Telegram в счёт не идёт.
- Экран «Игра не смогла запуститься» показывает список незагрузившихся файлов.

## 5.5 Переопределения функций (с доказательством)
Найдено 66 функций `G.*`, определённых несколько раз. 52 — обёртки (вызывают прежнюю, это нормальный приём). 14 — «чистые» перезаписи; из них удалены **13 прежних определений**, которые никто не вызывал: `rankName`, `jobTitle`, `friendDebt` (engine), `bankMenu`, `lendMenu`, `phoneMenu` (actions), `eatMenu`, `masterTalk` (data_actions), `friendMenu`, `girlMenu`, `friendsBlock` (v34), `relFace` (v35), `rankInfo` (v36). Минус ≈ 170 строк мёртвого кода.
Доказательство: (1) статически — между старым и новым определением нет захватов (`const _x = G.name`); (2) все 17 наборов тестов проходят; (3) экономическая симуляция (--quick, фиксированные seed) даёт **побайтно те же результаты** до и после. Оставшиеся 52 обёртки не трогались: их порядок существенен. `_bribeBusy` — флаг, а не функция, оставлен.
